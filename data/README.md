# Data locations

The GitHub source checkout includes the complete original paper dataset in [`raw/Multimodal data for prognostics.zip`](raw/Multimodal%20data%20for%20prognostics.zip). The first data-dependent command automatically extracts it to `data/raw/Multimodal data for prognostics/`. Extracted files stay outside Git; the single versioned ZIP is included in Git without requiring Git LFS.

To prepare and verify all files explicitly, run from the repository root:

```bash
python scripts/prepare_data.py --verify
```

The archive contains 50 equipment trajectories, 7,626 observations and the authors' original `Readme.docx`. See [attribution and data rights](DATASET-NOTICE.md) and [checksums](dataset-manifest.json). Existing local data is preserved.

`data/demo/` is generated by `mera-phm demo`. Generated demo data, model binaries and local run outputs are ignored by Git.

See [dataset documentation](../docs/dataset.md) for layout and target semantics. The original toy generator is in `prognostics/demo.py`.
