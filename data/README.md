# Data locations

`data/raw/` holds the original paper dataset, obtained separately. It is ignored by Git. `data/demo/` is generated locally by `mera-phm demo`; it is also ignored. No original dataset or trained model binaries are redistributed in this source repository.

See [dataset documentation](../docs/dataset.md) for layout, target semantics and attribution. The original toy generator is in `prognostics/demo.py`; its data checks installation and software behavior only.
