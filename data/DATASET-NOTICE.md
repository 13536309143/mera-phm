# Original dataset attribution

The archive `raw/Multimodal data for prognostics.zip` contains the unchanged dataset supplied with:

**Zhe Yang, Piero Baraldi, Enrico Zio.** *A multi-branch deep neural network model for failure prognostics based on multimodal data*. Journal of Manufacturing Systems 59 (2021), 42–50. [DOI: 10.1016/j.jmsy.2021.01.007](https://doi.org/10.1016/j.jmsy.2021.01.007).

The paper identifies the authors' original distribution page as <http://www.lasar.polimi.it/?page_id=2970>. The source archive preserves `Multimodal data for prognostics/Readme.docx`, including its dataset description and citation request. Cite the paper when using the data.

MERA-PHM does not claim authorship of these data. The repository's MIT license applies to the project code and original sample generator, not to this third-party dataset. The supplied dataset README requests citation and does not provide a separate redistribution license; this notice does not grant additional data rights.

The bundle includes all 7,977 original files: 7,626 TIFF images, 350 text files and the original README. The numerical evaluation fingerprint covers the 7,976 TIFF/text files. Bundle checksums, sizes, authors and source information are recorded in [dataset-manifest.json](dataset-manifest.json).
